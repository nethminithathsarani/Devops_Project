# Frontend

This folder contains the React client for BlogHub.

## Setup

```bash
npm install
npm start
```

## Environment

If you are not serving the frontend from the same origin as the backend, set `REACT_APP_API_URL` in a local [frontend/.env](.env) file.

Example:

```bash
REACT_APP_API_URL=http://localhost:5000
```

## Build

```bash
npm run build
```

The root [README](../README.md) contains the full project setup and Docker instructions.
